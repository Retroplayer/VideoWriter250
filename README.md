# VideoWriter 250 document recovery

Windows console utility under development to recover writings from Magnavox VideoWriter 250 floppy disks using Greaseweazle. **Read-only**: never writes to the original disks.

This repository is an initial development build. The decoder has only been tested against a limited set of recovered images, and the Greaseweazle drive path has not yet been hardware-tested.

The intended end-user workflow is to connect a Greaseweazle-equipped floppy drive and extract documents to individual TXT files, with RTF as an optional format.

See the Actions tab for Windows build artifacts once the build workflow has run.
